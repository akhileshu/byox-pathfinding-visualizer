# Task learning-contract prompt

Copy everything **below the first `---`** in [`roadmap-task-contract.md`](roadmap-task-contract.md) into your AI chat.

1. Fill **What I am building** with your task text (any source).
2. Optionally fill **Context**; delete unused optional lines.
3. Model returns usage scenarios, API contract, edge cases, and verification (ASCII or tables as fits the task).

**Pathfinding example:** paste a row from [`2_Pathfinding-Visualizer-Skill-Roadmap.md`](../2_Pathfinding-Visualizer-Skill-Roadmap.md) Practice Tasks table; Context `pathfinding-visualizer`, `TypeScript`, types `GridCell` / `Coord` if you want alignment with this repo.

**Non-roadmap example:** paste a single problem like “implement a min-heap priority queue” with Context `TypeScript`, no project line.
